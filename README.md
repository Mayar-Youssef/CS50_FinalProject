# French Resto - Restaurant Website

A sleek, modern, and responsive landing page for **French Resto**, an authentic French dining restaurant. Designed to present menu highlights, introduce the culinary team, and allow customers to easily reserve a table online.

## Key Features

- **Hero Landing Section(Home)**: Eye-catching dark theme header with action buttons for quick navigation and table booking.
- **About / Location Section**: Highlights the restaurant's background, story, and atmosphere.
- **Our Chefs**: Profile cards showcasing featured chefs (Chef Ahmed, Chef Mohamed, Chef Omar) with social links.
- **Special Dishes Showcase**: Highlighted menu favorites featuring Steak Frites, French Onion Soup, and Salade Niçoise.
- **Interactive Reservation Form**: Table booking form integrated with JavaScript validation to alert users if required inputs are missing or incorrect.
- **Footer Section**: Quick access to contact details, physical location, and opening hours.

## Technologies Used

- **HTML5**: Semantic markup structure.
- **CSS3**: Custom styling, layout design, and responsive elements.
- **JavaScript**: Client-side form validation and interactive alert notifications.
